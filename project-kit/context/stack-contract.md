# Stack contract

Existing locked versions: Vue 3.5.27, Vue Router 4.6.4, Vite 7.3.1,
Tailwind CSS 3.4.19, @vitejs/plugin-vue 6.0.3. Keep manifests and lockfile intact.

installed Playwright via PLAYWRIGHT_MODULE; document the exact verification environment.
